# 首页与侧边栏工具显示管理

> 切片：`A-POST-0.5-TOOL-VISIBILITY-001`
> 日期：2026-10-15
> 基线：`c9b8932e`；当前分支 `main`
> 状态：已完成；提交与推送结果见本轮交付记录

## 问题与范围

工具注册表已经支持全局隐藏，但首页和侧边栏共用一个可见状态。用户不能分别选择工具出现在哪个位置，也不能从一个固定入口恢复隐藏的工具。

本切片在 Settings 中增加工具显示页。每个已注册工具分别提供“首页”和“侧边栏”开关。设置保存在本机偏好中，并在当前窗口即时生效。Settings 入口保持固定，用户可以从这里恢复任一隐藏入口。隐藏只影响入口显示；工具仍注册，已有数据和配置不变。

本切片不实现卸载程序、删除插件文件、解除注册、清除工具数据或修改工具功能。

## 验收条件

- 已注册工具在 Settings 中显示，并有独立的首页与侧边栏开关。通过。
- 新工具默认在两个表面显示；关闭一个开关只隐藏对应表面。通过。
- 开关变化后首页和侧边栏即时更新。Settings 固定入口始终可用。通过。
- 本机偏好恢复已由 JSON 往返测试和启动加载代码覆盖；无效偏好不会阻断启动，未知工具 ID 会被忽略。通过。
- 隐藏和恢复不删除工具注册、工具数据、连接或配置。通过。
- 自动化测试覆盖两个表面独立切换、JSON 读写和无效偏好。真实窗口预览验证了设置页、开关、首页、侧边栏和恢复入口。通过。
